# Full Stack Open - Helsinki - DATABASE

Carpeta donde se encuentran desarrollados los modulos de la parte 13 del modulo de FullStack Open.
En esta modulo se llevan las practicas de conexión y uso de base de datos relacionales.

Entre los ejercicios desarrollados estan los siguientes:

## Part 13 - A
- 13.1 calculateBmi (paso 1: Creando una calculadora que pueda calcular el IMC en base a la altura y peso con Ts)
- 13.2 Gym Calculate (paso 1: Creando una calculadora de rendimiento en el Gym con Ts, usando interfaces y types)
- 13.3 Line Commands (paso 1: Cambiando la funcionalidad de los ejercicios anteriores para validar y usar la linea de comando)
- 13.4 Express/Ts  (paso 1: Agregango Express al proyecto y creando un endpoint con types para la API)
- 13.5 Express/BMi (paso 2: Creando un endpoint para poder utilizar la calculadora bmi mediante query params y types)
- 13.6 Eslint/Ts (paso 1: Configurando el proyecto para utilizar Eslint v9 con reglas para Ts y corrigiendo errores)
- 13.7 Express/Gym (paso 3: Agregando un endpoint para utilizar la calculadora del gym con un request tipo post)
